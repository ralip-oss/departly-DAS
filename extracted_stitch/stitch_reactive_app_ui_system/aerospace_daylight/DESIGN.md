## Brand & Style

This design system delivers crisp daylight legibility, frictionless departure intelligence, and architectural calm. Engineered for high-frequency travelers and professionals managing real-time schedules, the interface moves away from dark-mode tech grit toward an airy, contemporary terminal aesthetic.

The visual direction combines crisp Nordic minimalism with aerospace telemetry:
- **Luminous Terminal Clarity:** High-contrast light neutrals minimize visual noise and maximize daylight readability across gates, concourses, and outdoor transit.
- **Vibrant Kinetic Signals:** Vibrant Sky Cyan signals optimal flow and effortless departure, while Dynamic Coral alerts users to time-critical path variations and delays.
- **Precision Telemetry Typography:** Structural, confident headlines pair with Swiss body text and fixed-width monospace timing markers to keep critical timeframes immediately glanceable.
- **Identity & Logo Direction:** The wordmark features geometric, balanced letterforms paired with an integrated hybrid emblem: an upward-raking 45-degree departure wing intersecting a circular chronometer arc. The mark suggests synchronized departure, frictionless momentum, and time reclaimed.

## Colors

The light-first color architecture relies on high tonal contrast, subtle cool-tinted neutrals, and distinct operational chromatic accents.

- **Primary (`#29B6F6` - Vibrant Sky Cyan):** Signature brand color. Signifies verified itineraries, active departure countdowns, proactive guidance cues, and primary interactive triggers.
- **Secondary (`#FF6B57` - Dynamic Coral):** Status urgency color. Reserved strictly for tight transfer windows, transit delays, terminal changes, and critical travel alerts.
- **Neutral Canvas (`#F5F7FB`):** Pure, low-glare atmospheric tint serving as the default foundation for screens and application shells.
- **Surface Cards (`#FFFFFF`):** Base container fill for primary data displays, timeline segments, and flight modules, maintaining high optical separation against the canvas.
- **Raised Surfaces (`#EBF1F9`):** Tonal elevation for secondary chip trays, input fields, timeline nodes, and header bars.
- **Subtle Borders (`#E1E6F0`):** Crisp structural dividers and component perimeters ensuring crisp definition across light environments.
- **Text Primary (`#0F172A` - Deep Slate):** Core content, schedule times, gate identifiers, and primary headings.
- **Text Muted (`#64748B` - Cool Slate):** Supporting captions, flight status disclaimers, monospaced metadata keys, and inactive nav icons.

## Typography

Typography establishes an unambiguous visual hierarchy between destinations, operational data, and logistical narratives:

- **Headings (Space Grotesk):** Provides confident modern geometry and athletic poise. Applied to airport codes, travel phases, primary milestones, and modal headers.
- **Narrative & UI (Inter):** Highly legible, neutral workhorse. Applied to notifications, travel advice, itinerary body text, and settings configurations.
- **Chrono & Flight Telemetry (JetBrains Mono):** Monospaced precision for gate indicators, flight numbers, countdown tickers, boarding windows, and time stamps. Fixed tabular figures eliminate visual shifts as real-time countdown clocks update dynamically.

## Layout & Spacing

The layout model is driven by an 8-point spatial system designed for immediate information intake on the move:

- **Desktop (1200px+):** 12-column responsive layout. Three functional panes: a persistent contextual navigation sidebar (260px), a primary itinerary and route overview central area (8 columns), and an anchored dynamic chronometer card pane (4 columns).
- **Tablet (768px - 1199px):** 8-column layout. The live trip progress panel shifts to a persistent collapsible bottom sheet, while flight stages flow in a two-up grid.
- **Mobile (< 768px):** 4-column responsive layout with 16px screen margins (`margin-mobile`). Prioritizes a vertically scrolling live agenda card stack anchored by an ergonomic thumb-zone action bar.

Component margins and inner paddings use strictly defined increments: `space-xs` (4px) for tag insets, `space-sm` (8px) for icon-to-text gaps, `space-md` (16px) for item separation inside cards, `space-lg` (24px) for master card containers, and `space-xl` (40px) for section headers.

## Elevation & Depth

Visual depth is achieved through crisp tonal layering, soft ambient daylight drop-shadows, and deliberate border strokes:

- **Level 0 (Canvas):** Flat base surface (`#F5F7FB`).
- **Level 1 (Cards & Data Tiles):** `#FFFFFF` background with a hairline border (`1px solid #E1E6F0`) and subtle ambient shadow: `0 2px 8px -2px rgba(15, 23, 42, 0.04), 0 1px 2px 0 rgba(15, 23, 42, 0.02)`.
- **Level 2 (Floating Itinerary Modules & Overlays):** `#FFFFFF` with `0 12px 28px -6px rgba(15, 23, 42, 0.08), 0 4px 12px -2px rgba(15, 23, 42, 0.04)` and a refined border stroke of `#E1E6F0`.
- **Level 3 (Modals & Real-time Action Flyouts):** Elevated modal cards over a translucent scrim (`rgba(15, 23, 42, 0.35)` with 8px background blur), with high-dispersion shadow: `0 24px 48px -12px rgba(15, 23, 42, 0.14)`.
- **Focus & Glow Indicators:** Active elements incorporate directional accent halos:
  - Default Active Cue: `0 0 0 3px rgba(41, 182, 246, 0.25)`
  - Critical Departure Delay: `0 0 0 3px rgba(255, 107, 87, 0.25)`

## Shapes

The geometric framework balances structural card architecture with tactile, ergonomic touch triggers:

- **Cards & Primary Modules:** Standardized to a generous 20px radius (`1.25rem`), providing a refined modern contour that frames live trip data effortlessly.
- **Action Buttons & Status Chips:** Full pill geometry (9999px) for primary actions, transit pills, airport code chips, and real-time step trackers.
- **Inputs & Nested Containers:** Standardized at 12px (`0.75rem`) to nest inside 20px parent cards while maintaining uniform internal margin visual lanes.
- **Stroke Weights:** Component borders, field perimeters, and dividers maintain a uniform 1px thickness. System iconography utilizes crisp 2px line weights with rounded caps.

## Components

### Buttons
- **Primary Action (Pill-shaped):** Background `#29B6F6`, text `#FFFFFF`, typography `Space Grotesk` 14px SemiBold. Hover elevates color to `#1BA6E6` with a soft cyan shadow: `0 4px 14px rgba(41, 182, 246, 0.35)`.
- **Secondary (Tonal Pill):** Background `#EBF1F9`, text `#0F172A`, 1px border `#E1E6F0`. Hover shifts background to `#DEE6F2`.
- **Urgent Action (Delay / Rebook):** Background `#FF6B57`, text `#FFFFFF`. Hover brightens to `#F05742` with an ambient glow: `0 4px 14px rgba(255, 107, 87, 0.35)`.

### Chips & Gate Badges
- Pill-shaped (28px height). Background `#EBF1F9` with a subtle 1px `#E1E6F0` perimeter border.
- Text rendered in `JetBrains Mono` 11px uppercase (`#0F172A`).
- State variations include a 6px circular indicator: Cyan for on-schedule/boarding, Coral for delayed, and Slate for completed.

### Form Inputs
- 48px height, 12px corner radius. Background `#FFFFFF`, 1px border `#E1E6F0`, placeholder text `#64748B`.
- Focus state: Border illuminates to `#29B6F6` paired with an outer focus ring (`0 0 0 3px rgba(41, 182, 246, 0.2)`).

### Flight & Departure Cards
- 20px corner radius, `#FFFFFF` surface, 1px border `#E1E6F0`, padded with `space-lg` (24px).
- Internal layout features a three-part layout: departure station code and timestamp on the left, central travel path indicator line with flight icon and telemetry duration in `JetBrains Mono`, and destination arrival point on the right.
- Delay states introduce a dynamic 4px Coral accent bar along the top edge.

### Checkboxes & Radio Controls
- Checkbox: 20px rounded square (6px radius), 1.5px border `#E1E6F0`. Checked state fills `#29B6F6` with a white checkmark.
- Radio: 20px circular pill with 1.5px border. Active state features a 10px solid `#29B6F6` inner dot.

### Departure Countdown Dial
- Signature component: 72px circular progression ring showing live time-to-departure. Outer track in `#EBF1F9`, animated progression stroke in `#29B6F6` (or `#FF6B57` if under 20 minutes to boarding), with a center readout displaying minutes remaining in `JetBrains Mono`.
